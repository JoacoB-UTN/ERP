# Issue tracker: GitHub

GitHub issues in JoacoB-UTN/ERP are the issue tracker. Use the authenticated
GitHub CLI. Keep existing prompts/planned and prompts/completed task records;
link an existing task rather than creating a duplicate. Use a body file for
multiline issue and PR descriptions. Publishing comments or messages requires
user authorization. PRs as a request surface: no.

Follow AGENTS.md and docs/multi-agent-workflow.md for branch, dependency,
ownership, verification and review requirements. A skill does not grant merge
or production authorization; follow the user's current explicit authorization.
Keep PR #17 AI Agent Relay open and unmerged. Never assign concurrent ownership
of Prisma/migrations, packages/shared, auth, company-context, authorization,
audit or root configuration to independent agents.
